# Glossary

Every developer term used in Soulvee OS's guides, in six words each. When a new term comes up in a session, it gets added here.

## A–C

- **401 / 403**: the server's way of saying no.
- **Access token (SOULVEE_ACCESS_TOKEN)**: your own password for other devices.
- **Agent (AI agent)**: AI that uses tools to act.
- **API**: a service's door for other programs.
- **API key**: password a program uses to connect.
- **API version**: dated edition of a platform's API.
- **App Review (Meta)**: Meta's approval before apps reach customers.
- **Bot (Telegram)**: automated Telegram account run by software.
- **Branch**: parallel copy for changes, merged later.
- **Browser storage (localStorage)**: space each browser keeps for websites.
- **Buffer**: service that schedules posts to networks.
- **Build step**: converting code before it can run.
- **Cache**: saved copy kept for faster loading.
- **CI (automatic checks on GitHub)**: GitHub running your tests after changes.
- **CLAUDE.md**: instructions Claude reads at session start.
- **Cloudinary**: service hosting images at permanent links.
- **Command**: typed instruction the computer carries out.
- **Commit**: a labelled snapshot of saved changes.
- **Connector (claude.ai)**: link letting Claude use another app.
- **CSV**: spreadsheet saved as plain comma-separated text.

## D–L

- **Dependency**: someone else's code your project uses.
- **Deploy**: putting a new version live online.
- **Dev dependency**: tool needed for testing, not running.
- **Developer app**: registration that unlocks a platform's API.
- **Docker**: packs an app to run anywhere.
- **Docker volume**: folder Docker keeps when restarting apps.
- **End of life**: when software stops getting security fixes.
- **.env file**: private settings file holding your keys.
- **Environment variable**: a named setting a program reads.
- **Flaky test**: check that sometimes fails for nothing.
- **Git**: records every change to the code.
- **GitHub**: website where your repository is stored.
- **Graph API**: Meta's API for Facebook and Instagram.
- **Health check**: address showing whether the server's fine.
- **Hosting**: renting a computer that's always on.
- **https**: encrypted web connection; the padlock symbol.
- **JSON**: plain-text format programs use for data.
- **Library**: ready-made code a project can reuse.
- **localhost**: your own computer, as an address.
- **Lock file (package-lock.json)**: exact list of installed dependency versions.
- **Log file**: file where a program notes events.
- **LTS (Node.js)**: Node version with long-term security fixes.

## M–R

- **Make, Zapier, n8n**: services that connect apps without code.
- **Markdown (.md files)**: plain text with simple formatting marks.
- **Model (AI model)**: the specific AI that writes answers.
- **Node.js**: engine that runs Soulvee OS's server.
- **npm**: Node's helper for installs and commands.
- **npm run dev**: restarts the server whenever files change.
- **OAuth (sign-in)**: sign-in granting an app limited access.
- **Path**: a file's location, folder by folder.
- **Permissions (files)**: rules for who opens a file.
- **Persistent disk**: storage that survives restarts and redeploys.
- **Playwright**: drives a real browser during tests.
- **Polling**: asking repeatedly whether anything new arrived.
- **Port**: numbered door a program listens on.
- **Prompt caching**: reusing repeated parts to cut cost.
- **Proxy**: middleman passing requests between two computers.
- **Public address (PUBLIC_URL)**: your server's address on the internet.
- **Pull request (PR)**: changes proposed for review before merging.
- **Push**: sending your commits up to GitHub.
- **PWA (installable web app)**: website that installs like an app.
- **Queue**: waiting list of posts to send.
- **Rate limit**: cap on requests a service accepts.
- **React**: library that builds the app's screens.
- **Redirect address (callback)**: where a sign-in sends you back.
- **Refusal fallback**: declined requests retried on another model.
- **Repository (repo)**: a project's folder, with full history.
- **Request**: a program asking another for something.

## S–Z

- **Scheduler**: timer that sends posts on time.
- **Scopes**: the specific things a sign-in allows.
- **Script**: a file of instructions computers follow.
- **SDK**: ready-made code for using a service.
- **Server**: program that runs and answers requests.
- **Server-sent events**: how the server streams answers live.
- **Service worker**: lets the app open without internet.
- **Signal bridge (signal-cli-rest-api)**: community program connecting Signal to apps.
- **Signature (signed webhook)**: code proving a message is genuine.
- **Stand-in**: pretend service used safely during tests.
- **Streaming**: answers appearing as they're being written.
- **Structured outputs**: AI answers in a fixed shape.
- **Subagent**: a helper agent given one job.
- **System user (Meta)**: Meta account for apps, not people.
- **Tailwind**: ready-made style names for page design.
- **Terminal**: window where you type text commands.
- **Test (check)**: code that confirms other code works.
- **Test suite**: a group of related automatic checks.
- **Token (AI usage)**: chunks of text AI bills by.
- **Tunnel (Cloudflare Tunnel, ngrok)**: temporary public address for your computer.
- **URL**: the full address of a page.
- **Verify token**: shared password Meta checks during setup.
- **Webhook**: web address that receives automatic updates.
